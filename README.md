# Recount for Vanilla WoW

Recount is a lightweight combat analysis addon maintained for the World of Warcraft 1.12.1 client.

## Supported client

- Vanilla WoW 1.12.1 (`Interface: 11200`)
- This repository currently contains the Classic/Vanilla build only.

## Features

- Damage done and DPS
- Damage taken
- Healing done and healing taken
- Death tracking
- Current, overall, and saved fight segments
- Pet merging and class filtering
- Detailed player and ability breakdowns
- Group-ready reporting and configurable display settings

## Installation

1. Download the repository or the latest packaged release.
2. Copy the inner `Recount` folder into `Interface/AddOns`.
3. Confirm that the final path is `Interface/AddOns/Recount/Recount.toc`.
4. Restart the game or reload the UI.

## Commands

Enter `/recount` in chat for the available controls. The window also provides direct access to its display modes, segment history, reports, and configuration.

## Notes

This build targets the original 1.12.1 API. It is not presented as a TBC or WotLK port.
